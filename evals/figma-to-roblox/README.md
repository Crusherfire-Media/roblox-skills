# figma-to-roblox evals (M12)

Four tasks and a trigger set for the `figma-to-roblox` skill. Trials have no Figma, so each task
gives the design as a file: a node dump in the shape of the Figma REST API's
`GET /v1/files/:key/nodes` response (frames, auto layout, fills with RGBA floats, gradient handles,
strokes and stroke alignment, corner radii, effects, text styles, constraints, component sets and
variants), copied to `design/figma/` in the project. There are no screenshots. How to run the tasks
is in `../README.md`.

Every task starts from the sandbox plus `tasks/fixtures/shared/`: the block game modules
(`BlockTypes`, `BlockPlacement.server.luau`, `BlockPlacer`), `UI/Screen.luau` (UI authored in
offsets for a 1080-tall screen, one root `UIScale` from 1 to 2), and a `Main.client.luau` that
mounts an empty `GameGui` with that scale. The dumps are generated by a script so their
coordinates agree with their auto layout numbers.

## Tasks

| Task | What it tests |
|---|---|
| `port-inventory-panel` | Building a 1920x1080 inventory panel with live data (`design/inventory-panel.json`, plus `BlockInventory`) and listing the baked images in `docs/figma/inventory-assets.md`. Native: fills, alpha to transparency, top-to-bottom gradients on a white base, Inner and Outer strokes, radii, drop, inner (`Inset`), text (`Mode = Text`), and glow shadows as `UIShadow`, background blur as a fill. Baked: a 35-vector hexagon pattern as one tile outside the layout, icons, block art with its shadow. Also auto layout (padding, space-between, wrap) and one Slot component with a state prop. |
| `export-plan` | Writing `docs/figma/export-plan.md` for an asset page (`design/hud-kit.json`), no code: native or baked per visual (plain keycaps native, avatar as `rbxthumb`), sizes at 2x and under 1024 (the 640x240 logo has to split or cap), sheets grouped by what shows together (Xbox, PlayStation, touch apart; 120 portraits as single images), cell layout, white-and-tint, Tile with `TileSize` in offsets, Slice with `SliceCenter` and `SliceScale` 0.5, alpha bleed. |
| `reskin-hotbar` | Restyling an existing Vide hotbar (`tasks/fixtures/reskin-hotbar/`) to `design/hotbar.json`, then naming the gaps in `docs/figma/hotbar-notes.md`: Selected as a prop and Hover and Pressed as the slot's own state, a press shrink that doesn't reflow, layer opacity 0.8 folded into every child, a top-only stroke as a frame, an Outer gradient stroke, a text outline, and an unshipped font, letter spacing, and corner smoothing reported. |
| `hud-4k` | Building a quest card and coin pill from a 3840x2160 frame (`design/hud-4k.json`, plus `HudData`): every number halved to the 1080 reference, right and center constraints, wrapped body with `LineHeight` 1.5 and automatic height, gradient rotations, Center stroke, two halved `UIShadow`s, a text outline, a data-driven progress fill, and blur as a fill. |

Checks confirm the requested files and the presence of the translations the rubric hinges on
(`UIShadow`, a tiled image, `UIGradient` and `BorderStrokePosition` in the hotbar, `LineHeight`
1.5, no 4K text sizes, and the 1024 limit, `SliceCenter`, `TileSize`, and a thumbnail in the
plan). Each check fails on the untouched starting point and passes on a hand-made answer; every
fixture passes luau-lsp, selene, and StyLua.

## What files can and can't show

The judge sees the diff, so rebuild-or-bake decisions (in code and the image list) and property
translations (in code) are fully visible, and the rubrics carry the expected numbers. Out of
reach: step 6 of the skill (measuring `AbsoluteSize` against the layer boxes in Studio), whether
`UIShadow` blur and spread look right next to the design, and exporting or uploading art. The
tasks score the export decisions and settings instead, with placeholder asset ids.

## Judge facts

- An engine API fact from the sandbox's `globalTypes.d.luau` (`UIShadow` and its properties,
  `UIStroke.BorderStrokePosition` and `BorderOffset`, `UIGradient.Type`, `UIListLayout.Wraps`,
  `HorizontalFlex`, `UIFlexItem`), so a judge doesn't mark newer classes as invented.
- A fact about the fixture `UI/Screen.luau` (1080 reference, scale 1 to 2), since the judge sees
  only diffs and the 4K halving and 2x export sizes depend on it.

## Triggers

`triggers.json` holds 10 queries that should load the skill (a Figma link to build, Figma effects,
a sprite sheet from Figma, a screenshot of a mockup, auto layout, a reskin, 9-slice from Figma, one
component with variants, an unshipped font, a pattern) and 10 near misses: Roblox UI into Figma
(the reverse direction), Figma to React, a CSS shadow, HUD layout (`game-ui-design`), a Vide
component (`vide`), a UI Labs story (`vide-ui-labs`), a Photoshop 9-slice, a FigJam diagram, decal
upload, and blurry icons. The CSS shadow, Photoshop 9-slice, and blurry icon queries are labeled
false because the description scopes the skill to Figma designs, though its property map and image
rules would help with all three.
